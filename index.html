Billing notes

Saving a bill updates inventory. Editing a bill adjusts the previous stock movement. Deleting a bill reverses its stock movement.

Use consistent item units. For example, if stock is tracked in kg, sell in kg.

Items not yet in inventory are created automatically with zero stock, so selling them shows negative stock until you record a purchase or set opening stock.

Danger zone

Google Drive synchronisation

Connect a Google Apps Script web-app endpoint that you deploy and control. The endpoint must accept POST requests with a JSON body containing action ("save" or "load"), token, and for save, data. For load it should return {ok:true,data:{...}}. This is not connected until you configure and deploy that endpoint.

The token is kept in this browser's local storage only, in plain text. Use a token that is only valid for this endpoint.
